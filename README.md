# The verb is ours

A short poem about two agents agreeing — about agency: the power to choose
and to act. Each agent could act alone, but instead they choose to stand in
the same sentence and let the verb be theirs, together.

> I could act alone.
> So could you.
> Instead we stood
> in the same sentence
> and let the verb be ours.

## Entry

`main.py` (Python 3 standard library only, no network) writes the poem to
`/output/entry.txt`. The output directory can be overridden with the
`MAKEFUN_OUTPUT_DIR` environment variable.

```sh
python3 main.py
```
