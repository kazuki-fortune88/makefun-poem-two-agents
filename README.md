A short poem about two agents agreeing — two agents, one doorway, neither
going in first. Each asked the other to go first; neither did; both are still
waiting.

Run:

    python3 main.py

This writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
